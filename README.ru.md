# RED SEA

**Алгоритмический MIDI-секвенсор и CC-модулятор на одной плате ESP32-C3, управляемый погодными движками.**

**RED SEA** генерирует непрерывно эволюционирующую MIDI CC-модуляцию и нотный шаговый секвенсор, управляемые одним из пяти алгоритмических движков. Экран 128×32 OLED, один энкодер, четыре кнопки, стандартный DIN MIDI in/out. Разработано для аппаратной платформы [**ESPidi**, созданной Eugene Carlo](https://github.com/EugeneCarlo/ESPidi)

---

## Обзор

***RED SEA*** встаёт между источником MIDI-клока и подключённой аппаратурой. Он генерирует модуляцию Control Change по четырём назначаемым CC-параметрам и управляет 16-шаговым секвенсором нот/CC — оба процесса контролируются одним из пяти выбираемых алгоритмических движков:

- **FOG** — морфирующий LFO-движок (синус, треугольник или прямоугольник). Параметр SHAPE меняет саму форму волны, а не просто искажает её: на синусе добавляет гармоники, либо в другую сторону — клиппирует сигнал и подмешивает шум; на треугольнике плавно сдвигает форму к восходящей или нисходящей пиле.
- **SUN** — движок эхо-отражений. Когда значение параметра должно выйти за пределы диапазона, вместо простого ограничения запускается серия эхо-повторов, каждый следующий — с вдвое меньшим интервалом. Если нота секвенсора срабатывает на том же тике, что и старт серии, отражения также переигрывают эту ноту, транспонируя её всё дальше с каждым повтором.
- **RAIN** — движок стохастической модуляции. Четыре параметра могут независимо расходиться по времени с общим клоком, время от времени задевать соседний параметр и прерываться случайными событиями, которые выбивают параметр в минимум или максимум.
- **SNOW** — евклидовая заморозка. Мутация запускается евклидовым ритмом вместо фиксированного интервала. Каждый хит также может заморозить или разморозить любой параметр устройства, включая параметры самого движка.
- **TWST** — движок осколков, управляемый MIDI-входом. Каждая входящая нота звучит сразу и разлетается облаком копий, разбросанных по времени и высоте. Каждый удар также отбрасывает один из четырёх параметров от базового значения, после чего тот возвращается обратно. Работает без запущенного секвенсора.

## Возможности

- Пять алгоритмических движков (FOG / SUN / RAIN / SNOW / TWST), у каждого по четыре собственных параметра
- 16-шаговый секвенсор (нота, CC, третья назначаемая цель, ретриггер на шаг) с внешним или внутренним клоком
- У каждого CC-параметра свой MIDI-канал (или NO — ничего не отправляет); ноты секвенсора уходят на все каналы с отметкой Seq Trig
- Режим длины нот: легато или гейт
- Перфоманс-режимы BYPASS и FREEZE, включаются нажатием кнопки
- Freeze Roll: пока FREEZE удерживается, энкодер повторяет текущий шаг с частотой от 1/4 до 1/128
- MIDI Learn: захватывает номер CC и канал из следующего входящего сообщения Control Change
- Заморозка отдельных параметров, независимая от глобальных перфоманс-режимов
- Настройки записываются во флеш и сохраняются между включениями

## Железо

Эта прошивка разработана для аппаратной платформы **ESPidi**, созданной Eugene Carlo. Конкретно эта плата не обязательна — собрать совместимое устройство самостоятельно может кто угодно, распаяв ESP32-C3, OLED-экран SSD1306 128×32, энкодер и три кнопки по распиновке ниже.

| | |
|---|---|
| МК | ESP32-C3 |
| Экран | SSD1306 128×32 OLED, I²C |
| Ввод | 1× энкодер с кнопкой, 3× тактовые кнопки (PLAY / TAP / PAGE) |
| MIDI | Стандартные 31250 бод, DIN in/out через UART |
| Питание | USB-C |

Полная распиновка, жесты управления и постраничный справочник по параметрам — в [MANUAL.ru.md](MANUAL.ru.md). English version: [README.md](README.md) / [MANUAL.md](MANUAL.md).

## Сборка и прошивка

Прошивка — единый Arduino-скетч `REDSEA.ino`, написанный под Arduino core для ESP32. Собирается в Arduino IDE (плата: ESP32C3 Dev Module) или через `arduino-cli`. Зависимости: `Adafruit_GFX`, `Adafruit_SSD1306`, `Preferences` (идёт в комплекте с ESP32 core).

```bash
# arduino-cli, из папки REDSEA, в которой лежит REDSEA.ino
arduino-cli compile --fqbn esp32:esp32:esp32c3 REDSEA
```

Распиновка (авторитетный источник — `Pins::` в исходнике):

| Сигнал | GPIO |
|---|---|
| PLAY | 1 |
| TAP | 2 |
| PAGE | 3 |
| Кнопка энкодера | 4 |
| Энкодер A / B | 5 / 6 |
| MIDI RX / TX | 7 / 10 |
| OLED SDA / SCL | 8 / 9 |

## Статус

`main` — первая стабильная версия. `beta` — MIDI-каналы на каждый параметр, длина нот, Freeze Roll и движок TWST; в тестировании. Что изменилось с 1.0: [CHANGELOG.ru.md](CHANGELOG.ru.md). Issue и pull request приветствуются.

Обновление с первой версии: при первом включении прежний общий MIDI-канал копируется во все четыре параметра, так что устройство работает как раньше, пока вы сами не поменяете маршрутизацию.
